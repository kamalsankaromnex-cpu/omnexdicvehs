2. How to Integrate into Articulate Storyline 360

Follow these 4 steps for every quiz slide. No coding required inside Storyline.

1

Create the 4 Slide Variables

In Storyline's Variables panel, create these exact names (case-sensitive):

  • <ID>_Done — True/False (Default: False)
  • <ID>_Correct — True/False (Default: False)
  • <ID>_Answers — Text (or _Answer for Q006)
  • <ID>_Revealed — True/False (Default: False)
2

Insert the Web Object

Go to Insert → Web Object and select the built folder inside WebObjects/dist/:

  • Choose Display in slide.
  • Match the Web Object frame size to the quiz's canvas size (listed on each card above).
  • Never import from quizzes/ — always use dist/.
3

Add Submission Triggers

On the slide, listen for When variable changes: <ID>_Done:

  • If <ID>_Correct == True → Show Correct feedback layer (or jump to next slide).
  • If <ID>_Correct == False → Show Incorrect feedback layer.
4

Trigger Answer Reveal After Feedback

To avoid spoiling answers while feedback is open:

  • Keep <ID>_Revealed as False while the feedback popup is visible.
  • When the learner closes feedback, set <ID>_Revealed = True.
  • The Web Object immediately highlights the correct/incorrect cards.
Important: Do NOT use Storyline Desktop "Preview" (F12) to test quiz submission! Articulate Storyline's desktop Preview blocks Web Objects from talking to Storyline variables. Always test using Publish → Web, Publish → Review 360, or Publish → LMS (SCORM).

3. How Scoring, Retry & LMS Resume Work

What happens behind the scenes so learner scores and Oracle LMS progress stay accurate.

Learner Action What the HTML Quiz Does What Storyline / Oracle LMS Does
Clicks Submit Locks the cards, evaluates the answer key, and sends _Answers, _Correct, and _Done. Updates Life Meter / Reward Stars and opens the Correct or Incorrect feedback layer.
Closes Feedback Layer Waits quietly until Storyline sets _Revealed = True (no premature auto-reveal). Sets _Revealed = True on both Correct and Incorrect layers so review badges appear.
Retries Attempt (if enabled) Clears selection and unlocks cards when Storyline sends reset. Resets _Done = False and _Revealed = False before re-enabling the slide.
Revisits or Resumes in Oracle LMS Reads saved Storyline variables cleanly (even SCORM string "false" values) and restores locked/review state. Provides saved SCORM suspend data back to the slide on reload.
Need to update text, timings, or styles later? Developers edit the source in WebObjects/quizzes/ or WebObjects/shared/, then run python WebObjects/scripts/build_quiz.py once to refresh all 8 standalone folders in WebObjects/dist/.
