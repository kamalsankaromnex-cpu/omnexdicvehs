# Reference inputs that must be supplied by project owner

- `fonts/`: genuine licensed Daimler CS fonts (not bundled in this starter package); confirm web embedding rights.
- `design-guidelines/`: official brand guide PDF (if available).
- `quiz-screenshots/`: approved quiz UI images, including Q001.
- `approved-content/`: approved question wording, options, answer keys and source/version, no speculative answers.

Do not place secrets, API tokens, restricted training files or fonts into public repositories.
