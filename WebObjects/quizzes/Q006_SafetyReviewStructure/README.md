# Q006 — DICV Safety Review Structure

## 1. Primary Objective
Develop three independent scenario-based single-choice HTML Web Objects (`Q006_R1`, `Q006_R2`, `Q006_R3`) representing the three-tier DICV Safety Review Structure (Apex Committee, Sub Committee, Ad-hoc Committee – Initiatives).

## 2. Architecture & Rounds
- **Slide 1 / Q006_R1:** Organisation-wide Policy Review -> Apex Committee
- **Slide 2 / Q006_R2:** Critical Safety Performance Issue -> Sub Committee
- **Slide 3 / Q006_R3:** Machine-Guarding Improvement -> Ad-hoc Committee – Initiatives
