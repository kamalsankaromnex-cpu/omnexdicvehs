# DICV Reference Image Interpretation Protocol

**Core Directive:** Reference screenshots define **WHAT GOES WHERE**, never **HOW IT LOOKS**.

---

## 1. Two-Category Reference Analysis

Before implementing any new quiz from a user-supplied reference screenshot, analyze and document the image using these two strict categories:

### Category A — Preserve (Structural & Content Authority)
- **Question & Card Hierarchy:** Number of choices, arrangement, ordering.
- **Layout Structure:** Horizontal row vs. vertical stack vs. 2-column or 3+2 grid.
- **Card Content:** Icons, photographic thumbnails, option titles, option letters.
- **Interaction Type:** Single choice (radio), multiple response (checkbox), ordering, matching.
- **Source Copy:** Exact approved wording of question, instruction, and options.
- **Relative Proportions:** Visual balance between question, cards, and submit action.

### Category B — Override (Daimler Corporate Design Authority)
- **Colors:** Ignore teal, red, blue, purple, orange, neon green, or custom gradients. Apply the official Daimler Truck Corporate Petrol (`#00677F`) and Daimler Yellow (`#FFFF40`) palette.
- **Fonts & Typography:** Ignore non-Daimler fonts (Arial, Roboto, Montserrat) and eliminate slanted/italic question headings. Apply Daimler CS Regular & Bold upright.
- **Backgrounds:** Ignore decorative shopfloor illustrations, gaming console borders, neon chamfers, and sci-fi bevels. Use clean white panels with subtle corporate framing.
- **Selection States:** Ignore arbitrary colored checkbox fills and heavy black outlines. Enforce Daimler Yellow (`#FFFF40`) checkbox fills with Corporate Petrol (`#00677F`) card borders.
- **Buttons:** Ignore non-standard submit buttons. Enforce the Daimler stadium pill button with Corporate Petrol styling.
